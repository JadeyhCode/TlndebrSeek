# 发布清单（TlndebrSeek）

> 目的：任何一次对外发布都必须**可复现、可回退**。按顺序打勾，缺一项不发。

## 1. 代码与知识就位

```bash
git status --short          # 工作区必须干净（或只有本次改动的已提交内容）
sh code/build_code_model.sh # 知识改了才需要重建 code/code_model.bin
```

## 2. 一键门禁（唯一验收标准）

```bash
python3 tools/gate.py --suite
```

必须全绿，缺一不可：

| 项 | 通过线 |
|---|---|
| hidden | 328/328 |
| capbench（blind11–25）| PASS（没有组低于基线）|
| blind26 / 27 / 28 | 8/8 / 8/8 / 8/8 |
| blind29 / blind30 | 记录读数（不许回退）|
| suite | 全过（当前 122 套）|

**注意**：门禁必须**串行**跑——判官共用 `_t/work`，并行会读出假数据（实际踩过两次）。
`gate.py` 已经串行化，别手工并行跑判官。

## 3. 文档与版本

```bash
sh tests/selfcheck.sh       # 清单/脚本/文档引用一致性
# 改 ai.h 的 AIP_VERSION + CHANGELOG.md 顶部加一节
python3 tools/gate.py --suite   # 版本改动后必须重跑（selfcheck 会查一致性）
```

## 4. 打标与发布

```bash
git add -A && git commit -m 'Release Vx.yyzz：…'
git tag -a Vx.yyzz -m '…'
GIT_SSL_NO_VERIFY=1 git push https://<token>@github.com/JadeyhCode/TlndebrSeek.git main
GIT_SSL_NO_VERIFY=1 git push https://<token>@github.com/JadeyhCode/TlndebrSeek.git Vx.yyzz
```

GitHub Release 用 API 建（body 复用 CHANGELOG 里那一节）。

## 5. 发布后自检（必做）

```bash
rm -rf /tmp/tlnd_clean && git clone -q <repo> /tmp/tlnd_clean
cd /tmp/tlnd_clean && python3 tools/gate.py --quick
sh tests/plan.sh
```

干净克隆必须能自己编出 `build_aip`、自己建模型，且读数与开发机一致（§6.876）。

## 6. 回退办法

- 单个改动出问题：`git revert <sha>`，重跑门禁；
- 一批改动出问题：回到上一个 tag（`git checkout V<prev>`），重跑门禁后重新打标；
- 知识回退只需 `git checkout -- code/knowledge/*.triples` + 重建模型。

## 7. 不做的事

- 不逐关键词/逐表现的调优（结论：泛词会抢别的题，见 §6.859–§6.877）；
- 不在没有门禁表的情况下宣布“提升”；
- 不把“调过的集”读数当泛化能力。
