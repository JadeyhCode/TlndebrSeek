## 3. 关键用例：先教它，再撤掉推理前提

用虚构名词，避免它靠已有常识答对。

| 操作 | 外部实测表现 |
|---|---|
| 教学前问「纸鹭属于纸制品吗」 | 答「应该，这个我不太懂」，没有给出确定关系 |
| 依次教「纸鹭属于薄翅类」「薄翅类属于纸制品」 | 两条均确认记下 |
| 再问「纸鹭属于纸制品吗」 | **肯定，并输出两跳路径**：`纸鹭 → 薄翅类 → 纸制品` |
| 问第一条直接事实从哪来 | 正确回答：**「这条是你教我的（来源：教学留痕）」** |
| 问两跳结论从哪来 | 回答：**「图里早就有（语料，或者以前会话教的）」**，没有交代刚刚使用的两条前提 |
| 明确纠正「纸鹭不属于薄翅类」后，重问直接关系 | 回答否定，并展示否定边 |
| 再问两跳结论 | 不再给出原来的确定推导，改为「大概吧」，且明确标注**「其中一环是推测的，不是知道」** |

### 应当肯定

**前提变化真的改变了输出的证据等级。** 撤去前提后，系统没有继续把旧推导当确定事实；
也没有错误地推出「纸鹭一定不属于纸制品」。失去一条证明路径，不等于反命题成立。
这比「收到纠正后说一声抱歉」强得多。

### 应当批评

**回答结论与回答出处没有使用一致的依据。** 「这条结论不是你直接教的」本来可以是正确区分；
但紧接着说「图里早就有」，不是本次可见证据支持的解释。它刚刚展示的理由明明是两条本轮教学关系。

> **能展示路径，不等于后续能忠实解释路径。**

外部测试认为这是最值得拿回去对照灵枢的一条结果。

## 4. 自然语言入口：图上的能力强于「把话接进图」的能力

同一组教学内容，分别从同一初始模型副本启动：

- `我教你，绒塔属于蓝盒` → 「这个我不太懂」；下一轮问「绒塔属于什么」，仍不认识。
- `我 教 你 ， 绒塔 属于 蓝盒` → 当场造词并记下；随后能回忆、说出「你教的」、接受否定纠正。
- 但不带「我教你」前缀的 `纸鹭属于薄翅类`，**不加空格也成功**。

所以不能笼统断言「它不支持无空格中文」；实测是**等义表达走不同入口，结果可能不同**。

## 6. 与《智能论》白箱三问对照

《智能论》的判据不是「源码开放」或「不用大模型」，而是逐个回答追问：
**依据什么、什么条件下成立、错了怎么办。**

| 白箱三问 | 本项目的实际对应 | 外部判断 |
|---|---|---|
| **依据什么？** | `derive.h` 区分事实、规则、默认推测、缺口与结论；实测能显示两跳路径，直接教学事实也可溯源。 | **内核有依据，回答层部分成立。** 派生结论的出处追问出现错配。按同一张图重推能检验推导，不等于独立确认前提在现实中为真。 |
| **什么条件下成立？** | `xe.h` 的词—空符号—意义结构分离词面与词义；`claim.h` 的待证机制区分「听说」与事实边。 | **区分了词义、来源和使用资格，但三者不能互相替代。** 有路径表示图上可达，不等于该路径的前提已被观测证实。 |

> 外部测试固定在 `07a131a`；当前 HEAD 比它多两个提交（`ce807c2`、`b104545`）。
> 这两个提交只动文档与 `.c7b` 分片工具，**主链路源码（`main.c`/`agent.h`/`ai.h`/`rel.h`/
> `derive.h`/`think.h`/`micro.h`）没有变化**，所以行为结论仍适用。
> 为确认结论是否仍适用，在**不修改代码**的前提下，用当前 `build_aip` + `model.bin`
> 的临时副本复跑了关键路径。

### 8.1 派生结论的出处仍然错配

```sh
cp model.bin /tmp/m.bin
printf '::teach 纸鹭 属于 薄翅类\n::teach 薄翅类 属于 纸制品\n\
纸鹭 属于 纸制品 吗\n你 怎么 知道 纸鹭 属于 纸制品\n::quit\n' \
  | ./build_aip --model /tmp/m.bin
```

实测：

```
[教 会 了] 纸鹭 属于 薄翅类
[教 会 了] 薄翅类 属于 纸制品
AI > 对 ， 纸鹭 -[属于·传递]-> 薄翅类 ； 薄翅类 -[属于]-> 纸制品
AI > 这 条 **不 是 这 次 会话 教 的** —— 图 里 早 就 有（语料 ， 或者 以前 会话 教 的）
```

直接事实的出处仍然正确：

```
[教 会 了] 纸鹭 属于 薄翅类
你 怎么 知道 纸鹭 属于 薄翅类
AI > 这 条 是 你 教 我 的（来源 ： 教学留痕）
```

**结论**：两跳结论的出处错配在 HEAD 仍可复现。定位（未改代码）：
第一轮回答两跳结论时，思维层把 `纸鹭 --[属于]--> 纸制品` 沉淀成了一条
`role=推论` 的缓存边；下一轮问「你怎么知道」时，`agent_provenance` 先看到
「图上有这条直接边」，于是给出了「语料里早就有」的说法，而没有检查这条边是
本轮推出来的缓存、也没有把底层两条前提重新展开。

证据（同一进程里紧接着跑 `::edges 纸鹭`）：

```
[纸鹭] 有 4 条边：
  → 薄翅类        hits=30   ...  来源=共现
  → 属于           hits=1    ...
  → [属于·传递] hits=1    ...
  → 纸制品        hits=1    角色=4  来源=推论
```

最后一条就是"角色=推论"的缓存边。它是**推导沉淀**，不是语料，也不是本次直接教的。
所以「图里早就有（语料/以前会话教的）」这个说法不成立。

这是**文档记录的开放缺陷**，不是已修复项。

### 8.2 自然语言入口不一致仍然存在

```sh
printf '我教你，绒塔属于蓝盒\n绒塔属于什么\n::quit\n'    # → 「这个我不太懂」+「还不认识绒塔」
printf '我 教 你 ， 绒塔 属于 蓝盒\n绒塔 属于 什么\n::quit\n'  # → 「记下了：绒塔 属于 蓝盒（新词当场造）」
printf '纸鹭属于薄翅类\n纸鹭 属于 什么\n::quit\n'          # → 「记下了：纸鹭 属于 薄翅类（新词当场造）」
```

**结论**：无空格的教学前缀（`我教你，…`）仍走不到「现场造词 + 学习」那条入口；
无空格的关系陈述（`纸鹭属于薄翅类`）可以。两者不是同一层的问题。

### 8.3 `conv.sh` 仍然「有失败也 PASS」

`tests/conv.sh` 末尾固定打印 `PASS conv（$pass/$total 轮）`，没有 `[ "$fail" -eq 0 ]` 的退出码判断。
所以它**不能当门禁**用；看它必须看逐轮分子/分母与 `✗` 明细。这一点在外部测试之前就存在，
不是本次测试引入的。

## 9. 建议的端到端验收（「纸鹭九轮」）

外部测试给灵枢的建议，同样适合本项目作为**回归验收**，而不是再加一个抽象模块。
同一条派生结论应同时满足：

1. 教学前不冒充知道；
2. 教学后能指认**前提记录及所用规则**，并区分「教过的」与「推出的」；
3. 用户问「凭什么」时，解释必须与当轮实际走过的路径一致；
4. 撤回前提后，旧证明失效；若另有依据则展示新依据，否则降为待验或未知。

这四项测的是同一件事：**知识的生成、解释和失效，是否共用一条证据链。**
本项目已经把第 1、2、4 步的部分行为做到了可观察，也恰好用第 3 步的失败说明：
**不能把「图上有一条链」直接当作「系统已经白箱」。**

## 10. 对项目文档口径的修正

外部测试之后，以下说法应收窄：

| 原来的说法 | 应改成 |
|---|---|
| 「`::src/::whyfor/::der` 解释出处」 | 直接事实与规则前向链的出处可解释；**派生结论（尤其是思维缓存）的出处仍会错配**，见 §8.1 |
