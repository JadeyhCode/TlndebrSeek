## 0. 一句话

一个 **C11 单头文件**实现的**白箱（符号化、非神经网络）AI 实验体**：
记忆是图（符号节点＝词/概念，边＝关系/共现），理解是分词＋说法表＋关系求解，
思考是图上的议程循环，写作走"提议 → 安全内核审查 → 记账 → 应用"，
所有能力都用自建回归套件看护；"没做到"的地方一律照实写进文档。

- 版本：`AIP_VERSION = "0.08k"`（`ai.h:23`），存档格式 `MODEL_VERSION = 16`（`model_io.h:50`）。
- 当前分词：**全局默认滑动联想切分**（`sseg.h`，§6.968；训练/存读/帧库同样生效，旧最长匹配只在“切得更长”时兜底）。
- 切词修正：解析失败时自动**合并/拆开**重切（`::seg` 看合并/拆开次数）。
- 出厂模型 `model.bin`：**1285 个符号节点 / 41198 条边**（约 2.9 MB），已学 242176 次、21600 轮、
  49 次抽象、108 次睡眠。
- 代码规模：根目录 **49 个 `.h`，48773 行**；`main.c` 8627 行；三个语料生成器 `.c` 共约 1600 行。
- 仓库：1113 个受版本控制文件；316 次提交；tag `V0.08b`…`V0.08k`；最新提交：§6.967（滑动切分默认）。
- 许可：Wordless Source-Available License 1.0（非商业可读/可编译/可研究）。

## 1. 构建、运行、验收

```sh

# 代码知识模型（另一张图；合成器用）

sh tests/all.sh

# 一键门禁（hidden + capbench + blind 集，必须串行）

不给语料时尝试读 `model.bin`；都没有就用三句种子（`我 是 我` / `我 在 这里` / `你 好`）。

     ├─ ai.h           认知层：内生状态/元认知/生成/检索/emb/抽象/睡眠/GC/他者/时间/假设

     │   ├─ micro.h    微内核：修改意图队列 + 安全内核 + 补丁边界 + 检测器 D1–D4
     │   ├─ frame.h    结构化帧（问法/答法/槽位填充）
     │   ├─ rel.h      关系层 L2：关系表、五条规则、证明、独占判定、解析
     │   ├─ derive.h   推导：Derivation / 独立验证器
     │   └─ think.h    思维循环：议程、未解问题、机制注册表、元认知
     ├─ sseg.h         滑动联想切分（候选格/图支持度/词义激活；ai.h 末尾 include）
     ├─ lang_core.h    语言包核心（翻译，必须在分词前）
     ├─ drive.h        驱动层（情绪量 → 预算修正；内核只看到三个数字）
     ├─ action.h       受审的外部执行 + 写文件（白名单、超时、记账）
     ├─ code.h         写-跑-看错-改 + 有图知识驱动的代码合成
     └─ frame_io.h     帧库装载 / 图↔内存镜像

main.c 另外直接包含：token_lang.h（原语栈机）、lex.h（ASCII 代码词法）、model_io.h（存档）、
parts.h / corpus7b.h（局部加载/分片语料）、xbrain.h（跨脑知识）、pred.h（多元谓词）、
rule.h（Horn 规则+证明）、claim.h（待证）、arc.h（ARC 网格）、paper.h（论文）、net.h（arXiv）、

```

`think.h` 最后（它同时用求解器、验证器、意图队列）。

## 3. 数据模型（`token.h`）

### 3.1 Token（对外叫「符号节点」）

- `id`、`name`（池内驻留）、`meaning`（可选，带 codec 可存盘）、`owner`。
- `assocs/count/cap`：出边数组。**v10 起边上不再有语境字段**；访问必须走
  `token_assocs()` / `token_assocs_ro()`（为"边在磁盘上"预留，`tests/assocaudit.sh` 盯直接访问只许降）。
- 记忆状态 `mem_state`（ACTIVE/FADING/DORMANT/FORGOTTEN/GARBAGE）、`birth_tick/last_touch_tick`、
  `misses/recent_misses`、`hits`（在边上）。
- 结构字段：`parent`、`is_category`、`perspective_of`、`next_in_time`。
- 缓存：`emb`（1024 维 int8，惰性构建）、`n_ch/ch_len/ch_p/ch_sig`（名字字符切片与字符位图，
  用来做整句检索的精确预筛）、`cache_next/cache_q`（只把"挂着推论边"的词放进复核队列）。
- 反查：`rev_head`（入边倒排桶头）、`has_causal`、`edges_dirty`、`in_degree`、`rel_in_degree`。

### 3.2 AssocEntry（边）

一条边约 40 字节：`main/action` 两个端点、`hits/seq`、出生/最近 tick、`tset[4]/n_tset`（时刻集合）、
`mem_state`、`role`、`topic`、`pattern`（离句尾几个词）、`rel`/`nrel`（核心关系肯定/否定 16 位掩码）、
`dyn`（动态关系 id）。

- **role（来源）**：共现 0 / 输入 1 / 回复 2 / 造词 3 / 推论 4 / 基准 5 / 过程 6 / 想象 7。
  生成时"只沿同一角色走"是回复不跑偏的关键；`::src`、`::edges` 用它回答"哪来的"。
- **rel 位掩码**：`属于/有/会/怕/喜欢/吃/在/包含/需要` 九个核心关系（id 1–9）；
  `REL_DYN_BASE = 10` 起是动态关系（开放谓语，最多 `AI_MAX_DYNREL`，现 96）。
- **控制流记号**挂在 `action` 槽上：`[步骤:N]`、`[调用]`、`[回边]`/`[回边:条件]`、
  `[条件:X]`、`[否则]`、`[异常:类型]`、`@要:…`、`@说:…`；过程根是 `[过程:名字]`。
- 索引与加速：`rev_*` 反查倒排（只追加、读时校验）、`ebloom` 边存在性布隆过滤器
  （把"写一条边"从 O(出度) 降到 O(1)，无假阴性）。

### 3.3 TokenPool

`tokens[]`、全局单调 `serial`、名字哈希桶、`unknowing` 占位、`current_tick`、`loading`（装载期不记观测）、
`parts`/`part_load`/`part_touch`（局部加载钩子）、`ebloom`、视角栈、缓存复核队列、反查表。

### 3.4 亚符号与视角

- `emb`：PPMI × 随机索引投影（±1 随机向量）一遍生成，1024 维；不做多轮聚合（避免过平滑）。
  不写进模型文件，训练收尾/读盘后现算，且**读盘时可延迟到第一次 `::near/::analogy` 才建**。
- 视角：`PerspectiveNode` 树 + 当前视角；假设层（`Hypo`）是"读时覆盖层"，图本身不动。

### 3.5 存档（`model_io.h`，v16）

`[FileHeader 40B] [TokenRec × n] [AssocRec × total] [AIBlock]`，尾部按版本追加：
他者信念/改口历史（v13）、时刻集合（v12）、思考对象摘要（v11）、"因为"表（v15）。
v16 把**边独立成段**、变长编码、默认值省略，读盘单趟完成；`saveio.h` 提供"唯一临时名 + fsync + 原子 rename"，
避免两个进程写同一个 `model.bin.tmp`。反向读取兼容 v1–v15。`model_io_v16.h` 只是 v16 边/词的
变长编解码小头，被 `model_io.h` 引用。

另有一层**图的不变式自检**（`aicheck.h`）：池的 `id==下标`/`owner`、边只有三种合法形态
（RAM 数组/DISK 哨兵/空）、端点同池且不自环、名字都能 `pool_find` 回来、反查表覆盖每条关系边、
修改账只记活 id、局部加载后指针一致。`tools/bughunt.c`、`durableprobe.c`、`learnprobe.c`
在**每一步之后**跑它——用来抓"照样答得对、但图已经坏了"的那类 bug。

## 4. 运行主循环

`main()`：解析参数 → `agent_new(stdin_perceive, stdout_act, NULL)` → 可选训练 → 可选加载模型 →
打印统计 → REPL。REPL 先按 `::`/`:` 拆命令，**查唯一一张命令表** `CMDS[]` 拿 id 再 `switch`
（帮助也从表生成；`tests/cmdtable.sh` 把帮助里每条命令真打一遍）。135 条元命令。

`agent_step(a, input, out, cap)` 是每轮的总入口，优先级大致如下（源码里都带 §6.x 编号）：

1. 轮次准备：tick+1、奖励衰减、清 `learn_note`、恢复挂起的追问、记录用户原话。
2. 最高优先的对话胶水：回答格式（"用X格式回答"）、待确认的"要改掉旧的吗"、追问回话（askback）、
   "我刚才教了你什么"、"刚才聊了什么"。
3. `[reply]` 桶（数据表关键词命中）→ 自我/能力路由 → 裸短回话。
4. 预处理：条件缓存复查、驱动折算；**语言包翻译**、代词消解、更正前缀剥离、
   全称/定义句归一（都在分词之前）。
5. 分词（`ai_tokenize`，池内最长匹配；可加载 `lexicon.txt` 扩展）或逐字模式。
6. 各类"带结构的学习/回答"入口：谓词出处、待证（听说/据说）、亲属句、属性教学、
   地点块、自然说法新词（默认关）、属性句、`因为` 原因、理由层、奖励事件等。
7. **关系层**：陈述即学（写入关系边）、问句即求解（`rel_solve`）、先链后联想、类比兜底。
8. **帧层**（结构化问法/答法 + 槽位填充 + Gate B 关联链放行）→ **整句检索**（字符 bigram 打分 +
   覆盖率/IDF/话题）→ 逐词游走生成 → 兜底说法池。
9. 收尾：脏思考截停、记 `last_reply`、元认知/表达前缀、更新上一句主语、
   微内核安全点（`micro_step`）、对话触发、过程记号、输出侧补丁、
   维护（巩固 / GC / 睡眠，可分段计时）、漂移/诊断/叙事。
10. 每轮答复都带一个**来源标记**（`AI_SRC_OTHER/REPLY/SELF/BARE/RELATION/FALLBACK/FRAME/RETRIEVAL/NOTE`），
    `tools/srccount.py` 用它统计"答复从哪来"。

## 5. 语言与说法层（`agent.h` 的大头）

### 5.1 十九张说法表（数据优先，代码只留种子）

`patterns.txt` 的桶：`[lead]` 引导语、`[tail]` 句尾、`[slot]` 占位词、`[confuse]` 没听懂、
`[syn]` 同义词、`[affix]` 词缀、`[fill]` 填充词、`[class]` 词类、`[say]` 答复模板、
`[shape]` 语序改写、`[reply]` 关键词答复、`[qword]/[qpart]` 疑问词、`[bare]` 裸回话、
`[alias]` 关系别名、`[measure]` 量词、`[refuse]` 拒答说法、`[pron]` 代词、`[verdict]` 判词组。
`::pattern sync` 把 19 张表写成图事实（`引导语库 --[有]--> 劳驾?` 等），之后**教一条即可扩展**；
`AIP_NODATA=1` 用来做"无数据"消融。

- `[shape]`：等长词序列重排，`$n` 捕获一个词，`@k` 要求词在池中，`@r` 要求是关系词；
  例：`$1@k 你 $2@r 吗 = 你 $2 $1 吗`。新语序＝加一行。
- `[reply]`：组间 `,` 是 AND、组内 `|` 是 OR，`^` 表示整句精确，`@class` 引用词类。
- `[say]`：带槽位的答复模板（`$1`/`$2`），把"判词/组织/不知道/列表/历史/过程/假设/信念…"全部下沉。

### 5.3 原语与栈机（`token_lang.h`）

31 条原语（`[原语:对象/好/坏/分割/请求/执行/拒绝/包裹/前关联/连接/断开/创建/运行/如果/否则/结束/
激活/嵌套/展开/视角/认为/引用/现在/之前/之后/时间链/前关联不/前提接线/插词/插词为/回收临时]`）。

`token_check_program` 是干跑校验器（`::asm check on`），认未知原语、括号不配对、操作数不够、

### 5.4 结构化帧（`frame.h`）

`FrameSet = Frame[]`，每帧若干问法模板、答法模板、槽位与填充类；上限 64 帧 / 16 模板 / 8 槽 / 48 填充。
生成 = 匹配问法 → 认出用户改了哪个槽 → 用同一个槽渲染答法，因此能说出"语料没写过但骨架合法"的句子。
两个放行闸门：Gate A 手写白名单；Gate B 用邻居 Dice 证据（有实词/成形词/相似度≥40 三道门）。
`frame_io.h` 负责从文件或**图里的帧事实**装载，`::framesync` 校验镜像一致。

## 6. 推理与思维

### 6.1 关系层（`rel.h`）

- 三态真值：+1 真 / -1 假 / 0 未知。**未知时不许说"不对"**（开放世界默认；`::world closed` 才闭合）。
- 规则：R0 直接、R1 传递、R2 继承、R3 对称、R4 逆关系、R5 类比（标"推测"）、
  R9 缺前提否定能力、R10 前提/反前提；`Proof` 记录每一跳、极性、规则、是否来自假设/缓存。
- "独占"判定用**似然比**（非手写阈值）：`rel_excl_single/multi/llr`，`::excl` 全打出来；
  属于/在 判为独占，有/会/怕/喜欢/吃/需要 判为多值（以数据为准，可推翻声明）。
- 自然说法：关系别名（害怕→怕、具有→有…）、`能/可以`→会、`是一种X` 剥量词；
  开放式问句（`A R 什么` / `谁 R B`）走正/反向扫描。
- 解析 `rel_parse` 只做"能落成三元组"的判断；`allow_new` 决定是否登记动态关系（问句不登记）。

### 6.2 推导与验证（`derive.h`）

`Derivation` = 目标 + 步骤（GOAL/FACT/RULE/DEFAULT/GAP/CONCLUDE）+ 真值 + 缺口数 + 是否推测。
`der_verify` 不信任构造结果，用求解器**独立重推**每一步；有缺口就不许下结论。
`der_say/der_dump` 按风格（结论/结论+链/只链/符号）渲染——文字只是链的投影。

> **外部测试发现的开放缺口（2026-11-19）**：推导本身能给出两跳路径，直接教学事实也能溯源；
> 但**派生结论的出处追问**会错配——问「你怎么知道 A R C」时，若思维层已把 A→C 沉淀成
> `role=推论` 的缓存边，`agent_provenance` 会先说「图里早就有（语料/以前会话教的）」，
> 而不是交代刚才那两条前提。详见
> [外部独立测试-07a131a-白箱三问.md](外部独立测试-07a131a-白箱三问.md) §8.1。
> **能展示路径，不等于后续能忠实解释路径**——本节不能据此宣称"出处已端到端接稳"。

### 6.3 思维循环（`think.h`）

一轮 = 立目标 → 取目标 → 挑手段（查/推/类比/查矛盾/换问法/经中间词/借最近邻/需要/前提/传递）→
够不着就拆子目标压回议程 → 直到有结论 / 停滞 / 预算用完，并写明停因。
铁律：**想出来的不等于真的**（必须 `der_verify` 过）；**思维不往图里写猜测**（只能经意图队列提议
`[自问:…]` 或沉淀缓存）；**想不通是合法结果**。跨轮未解问题会过期；元认知看"打转/挂太多/自相矛盾"。
可选：`::thinkobj`（思考对象+复核）、`::thinkredo`（回溯换路）、`::idle`（空闲只读思考）、
`::selfgoal`（从"常用但薄/一开口没底"的词自建目标）。

### 6.4 微内核（`micro.h`）

```
学习/激活/补丁 → 只提议 ModIntent → 队列 → 安全内核(safety_review) → 应用 + 记账 → 审计
```

## 19. 安全边界与失败模式

- **外部世界**：默认关；只 https；主机名精确白名单；不用 shell；每次 ≤2 MB/≤15 s/≤8 次；
  不跟重定向、不碰 Cookie；密钥只在本机 `tool.txt`（gitignore）；外部答复**不进图**。
- **自修改**：关系边不可删；保留名不可改；预算与池上限；越界即冻结；每条拒绝有理由；
  审计环可查（`::safe`）；失败补丁自动停用。
- **写入**：关系事实走统一通道并记来源；`route_writes` 可把知识写入改走意图队列；
  `verifywrites` 写后读回复核；`wgate` 按重要度分档拦截情境层写入。
- **持久化**：原子写（临时名+fsync+rename）；v16 读盘单趟；坏档返回 NULL 而不是半截图；
  局部加载下 GC 会跳过（`n_gc_skipped_partial`），不误删磁盘上的边。
- **输出**：脏思考检查器截停连续重复；元认知不确定才加"大概/不确定"；有缺口不下结论。
- **测试可信度**：判官必须串行；套件命令不能用管道收尾；结果数必须等于任务数；
  `selfcheck` 专抓"汇总看着绿其实没测到"。
