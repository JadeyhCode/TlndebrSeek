## 自学属性校验原语（§7.012，`main.c`，不在 code.h 扫描范围）

> 为什么仍在 C：它们要**执行候选程序**再判性质（读文件/跑进程/比数值），图里表达不了“执行”。
> 规则（哪个关键词用哪个性质）在 `code/knowledge/verify.triples`；C 只留通用原语。
> 消融：删掉 verify.triples 里的对应规则 ⇒ 该题变“未验证”放行（可见行为退化）。

| 原语 | 判什么 | 为什么不能进图 | 消融测试 |
|---|---|---|---|
| `区间` | 单值输出在输入 min..max 之间 | 要跑程序 | 删规则后不再校验（`studyeval` 读数会变） |
| `均值` | 输出 == floor(Σin/6)（两组固定输入） | 同上 | 同上 |
| `相邻差最小` | 输出 == min|in[i]-in[i-1]| | 同上 | 同上 |
| `上界差` | 0 ≤ 输出 ≤ max-min | 同上 | 同上 |
| `子集偶数` | 每个输出都在输入里且为偶数 | 同上 | 同上 |
| `公因数` | 输出 == **最大**公约数（不是任意公因数） | 同上 | 同上 |
| `最大值` / `最小值` | 输出 == max/min(输入) | 同上 | 同上 |
| `平方和` | 输出 == Σin² | 同上 | 同上 |
| `奇数和` | 输出 == Σ奇数输入 | 同上 | 同上 |
| `第二大` | 输出 == 第二大（去重语义） | 同上 | 同上 |
| `中位上` | 输出 == sorted[3]（上中位） | 同上 | 同上 |
| `字符串长度` | 输出 == len("ab cd ef")=8 | 同上（要跑程序） | 同上 |
| `单词个数` | 输出 == 3（"ab cd ef"） | 同上 | 同上 |
| `翻转单词` | 输出 == "ef cd ab"（去空格比） | 同上 | 同上 |
| `回文` | "abcba"⇒yes、"abc"⇒no | 同上 | 同上 |
| `成员` | 输出是输入之一 | 同上 | 同上 |
